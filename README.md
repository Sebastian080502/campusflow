# CampusFlow

> Plataforma web para la gestión y seguimiento de solicitudes y servicios universitarios.

## Descripción

CampusFlow es un proyecto académico de la asignatura **Arquitectura de Software**, cuyo propósito es diseñar y desarrollar una plataforma web que centralice la gestión de solicitudes realizadas dentro de un entorno universitario.

La plataforma permitirá a los usuarios registrar solicitudes, consultar su estado y realizar seguimiento al proceso de atención, mientras que el personal encargado podrá gestionar y dar respuesta a dichas solicitudes.

---

## Problema

En los entornos universitarios pueden existir diferentes solicitudes relacionadas con servicios académicos, administrativos, tecnológicos o de infraestructura.

Cuando estos procesos se gestionan mediante diferentes canales, pueden presentarse problemas como:

- Dificultad para realizar seguimiento a las solicitudes.
- Información dispersa.
- Falta de claridad sobre el estado de una solicitud.
- Dificultad para identificar responsables.
- Pérdida del historial de atención.
- Procesos manuales y poco centralizados.

---

## Solución

CampusFlow busca centralizar estos procesos mediante una plataforma web que permita:

- Registrar solicitudes.
- Consultar y hacer seguimiento.
- Gestionar estados.
- Asignar responsables.
- Registrar comentarios y observaciones.
- Consultar el historial de atención.
- Organizar solicitudes por categorías.

El alcance y las funcionalidades definitivas serán determinados durante la etapa de análisis y definición de requisitos.

## Usuarios del sistema

Aunque el proyecto es desarrollado por un solo participante, la plataforma contempla diferentes actores que utilizarán el sistema:

- **Estudiante / Usuario:** registra solicitudes y consulta su estado y seguimiento.
- **Personal encargado:** recibe, gestiona y atiende las solicitudes asignadas.
- **Administrador:** administra usuarios, categorías, permisos y configuraciones del sistema.

Los roles y permisos definitivos serán establecidos durante el diseño del sistema.
