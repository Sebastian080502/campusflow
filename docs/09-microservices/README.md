# Catálogo de módulos

CampusFlow no es una arquitectura de microservicios. Esta carpeta conserva el nombre pedido por la estructura de documentación y describe los módulos del monolito.

| Módulo | Ficha |
| --- | --- |
| API | [api.md](api.md) |
| Cliente web | [web.md](web.md) |

No hay despliegue independiente por módulo, ni contratos de eventos entre procesos. La API y el cliente se construyen y se publican juntos.
