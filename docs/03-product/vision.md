# Visión

CampusFlow es la bandeja web donde la comunidad universitaria deja una solicitud y sigue su atención hasta el cierre.

- El estudiante registra y consulta lo suyo.
- El personal encargado toma, comenta y resuelve.
- El administrador mantiene usuarios y categorías.

La interfaz está en español. Las reglas viven en el servidor. El historial permanece aunque cambie el responsable.

Participante: Juan Sebastián Osorio Fierro, analista, arquitecto y desarrollador.
