# ADR 003 — JWT bearer

## Estado

Aceptada.

## Decisión

El ingreso devuelve un JWT firmado con `JWT_SECRET` (mínimo 32 caracteres). El token dura lo que indique `JWT_EXPIRES_IN`; si no está definido, dura 8 horas. El cuerpo solo incluye `sub`. Cada petición protegida envía `Authorization: Bearer`. Las rutas públicas son registro, ingreso y salud.

## Consecuencias

No hay sesión de servidor. Revocar un token antes de las 8 horas no está en este incremento; desactivar la cuenta impide renovar el acceso en la siguiente validación del usuario.
