# Contexto

CampusFlow centraliza las solicitudes que una persona de la comunidad universitaria hace a un área de la institución: académicas, administrativas, tecnológicas, de infraestructura u otras.

Hoy esos pedidos circulan por correo, formatos sueltos y conversaciones. Quien solicita no ve un estado único, y quien atiende no tiene un historial compartido. CampusFlow guarda la solicitud, su responsable, sus comentarios y cada cambio de estado.

El sistema lo usa un estudiante, el personal encargado y un administrador, desde un navegador. La API aplica las reglas de rol y de estado. El cliente solo presenta lo que el servidor autoriza.
